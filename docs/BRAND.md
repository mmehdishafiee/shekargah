# هویت بصری شکارگاه

لوگوی شکارگاه یک **نشان قرینه** است: تاج‌مانند در بالا، ستون عمودی در میانه و دو بال که
در پایین به هم می‌رسند — به‌صورت گلیف سفید روی کاشی نارنجی «شکار».

## فایل‌های هویت

| فایل | جای مصرف |
| --- | --- |
| `src/components/brand/Logo.tsx` | `LogoMark` (سرصفحه، فوتر، صفحهٔ ورود، خطای پیکربندی) و `Logo` (نشان + واژه‌نما) |
| `public/favicon.svg` | آیکون تب مرورگر (برداری) |
| `public/favicon.ico` | ۱۶/۳۲/۴۸ — مرورگرهای قدیمی‌تر |
| `public/favicon-32.png` | آیکون PNG ۳۲ پیکسلی |
| `public/apple-touch-icon.png` | ۱۸۰×۱۸۰ — آیکون iOS و بوکمارک‌ها |
| `public/icon-192.png` / `public/icon-512.png` | آیکون‌های نصب اپ (PWA) |
| `public/icon-maskable-512.png` | آیکون maskable اندروید (نشان داخل ناحیهٔ امن ۸۰٪) |
| `public/og-image.png` | کارت اشتراک‌گذاری ۱۲۰۰×۶۳۰ (اوپن‌گراف و توییتر) |
| `public/site.webmanifest` | مانیفست نصب اپ |
| `docs/brand/crest.png` | نسخهٔ مرجع تصویر اصلی نشان |

## رنگ‌ها

| نقش | مقدار |
| --- | --- |
| کاشیِ نشان | `--color-logo-tile` = `#f54e02` |
| گلیف | `#fff` |
| رنگ اصلی دکمه‌ها | `--color-brand-600` = `#cc4a12` (تیره: `#ef6c2c`) |

رنگ کاشی عمداً از تم پیروی نمی‌کند: نشان برند در هر دو حالت روشن و تیره همان نارنجی
می‌ماند، ولی رنگ اکشن‌ها از توکن‌های `--color-brand-*` می‌آید.

## مسیر برداری

`CREST_PATH` در `Logo.tsx` مسیر SVG نشان است (سه زیرمسیر، `viewBox="0 0 32 32"`).
این مسیر با ردیابی تصویر مرجع ساخته شده و با تصویر اصلی بیش از ۹۹٪ هم‌پوشانی دارد.
فایل‌های `favicon.svg` و همهٔ PNGها از همین شکل ساخته شده‌اند؛ اگر نشان را تغییر می‌دهید،
هر دو جا (کامپوننت و فایل‌های `public/`) را با هم به‌روز کنید.

متن کارت `og-image.png` («شکارگاه» و «کشف محصولات تازه‌ی ایرانی») با فونت
Vazirmatn و همان نشان روی نارنجی برند ساخته شده است.
