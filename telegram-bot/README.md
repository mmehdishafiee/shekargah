# 🤖 ربات شکارگاه

ربات تلگرام **شکارگاه** روی **Cloudflare Workers** — محصولات تازه‌ی سایت را در کانال معرفی می‌کند و با یک کلیک کاربر را وارد حساب سایتش می‌کند.

## ✅ وضعیت استقرار

| | |
|---|---|
| آدرس Worker | https://shekargah-bot.lumg.workers.dev |
| سلامت | https://shekargah-bot.lumg.workers.dev/health |
| ربات | [@shekargaah_bot](https://t.me/shekargaah_bot) |
| کانال | شکارگاه — `@shekargaah_ir` |
| دیتابیس | D1 `shekargah-bot-db` (EEUR) |
| کرون | هر ۵ دقیقه (`*/5 * * * *`) |
| سایت | https://shekargaah.ir |

## ✨ امکانات

| امکان | توضیح |
|---|---|
| 📣 معرفی خودکار محصول تازه | کرون هر ۵ دقیقه محصولات تازه‌ی سایت (`status = published`) را در کانال پست می‌کند |
| 🎯 کارت محصول | لوگو + نام + شعار + دسته + رأی و دکمه‌های شیشه‌ای «دیدن محصول» و «محصولات تازه» |
| 🌐 فوتر پست کانال | زیر هر پست، **آیدی خودِ کانال** می‌آید: `🌐 @shekargaah_ir` |
| 🔐 ورود به سایت با تلگرام | بدون رمز و ایمیل؛ کد یک‌بارمصرف ۱۰ دقیقه‌ای → نشست Supabase در سایت |
| 📚 مرور محصولات در ربات | لیست صفحه‌بندی‌شده با کارت هر محصول و ثبت بازدید |
| 🗂 دسته‌بندی‌های سایت | همان دسته‌های سایت با تعداد محصول هرکدام؛ انتخاب دسته → لیست محصولات آن دسته (صفحه‌بندی‌شده) |
| 🏷 درباره | معرفی شکارگاه، امکانات سایت، ورود با تلگرام و لینک کانال |
| 🔔 اعلان در چت خصوصی | هر کاربر می‌تواند اعلان محصولات تازه را روشن/خاموش کند |
| ✍️ پست دستی کانال | متن یا مدیا با تا ۸ دکمه‌ی دلخواه + زمان‌بندی |
| ⏰ زمان‌بندی | معرفی محصول یا پست دستی در تاریخ/ساعت مشخص (به وقت تهران) |
| 📦 معرفی محصولات قبلی | بک‌فیل ۵ یا ۱۰ محصول اخیر با یک کلیک |
| 📊 آمار | کاربران، حساب‌های متصل، مشترکان، معرفی‌ها، بازدیدها |
| ⏸ تعلیق اعلان خودکار | توقف/فعال‌سازی پست خودکار بدون خاموش‌کردن کرون |
| 🔒 گیت عضویت کانال | با `REQUIRE_JOIN=1` **همه‌ی** امکانات ربات (مرور محصولات، ورود به سایت، اعلان‌ها) فقط برای اعضای کانال باز است؛ خطای گذرا کاربر را قفل نمی‌کند (fail-open) و ادمین‌ها معافند |
| 🧪 تست | ۴۰ سناریو بدون هیچ اتصال شبکه‌ای |

> **دکمه‌های شیشه‌ای** = همان دکمه‌های inline تلگرام که شناور زیر پیام می‌نشینند
> (نه کیبورد پایین صفحه). تلگرام امکان استایل‌دهی گرادیانی/شیشه‌ای به دکمه‌ها
> نمی‌دهد؛ شیشه‌ای‌بودن کامل در مینیاپ (صفحه‌ی وب) ممکن است.

## 👤 منوی کاربر

`/start` →

```
[ 📚 محصولات تازه ]  [ 🗂 دسته‌بندی‌ها ]
[ 🔐 ورود به سایت با تلگرام ]
[ 🔔 اعلان محصولات ]
[ 🏷 درباره ]  [ i️ راهنما ]
[ 🌐 باز کردن شکارگاه ]
```

- **📚 محصولات تازه** — صفحات ۵تایی از آخرین محصول‌های منتشرشده
- **🗂 دسته‌بندی‌ها** — همان دسته‌های سایت با تعداد محصول (مثلاً «وب‌اپلیکیشن (۱۵)»)؛
  انتخاب هر دسته → لیست صفحه‌بندی‌شده‌ی محصول‌های همان دسته → کارت محصول
- **🏷 درباره** — معرفی شکارگاه، بخش‌های سایت (امروز، رتبه‌بندی، داغ‌ترین‌ها، سازنده/شکارچی)،
  ورود با تلگرام و لینک کانال

## 🔄 جریان معرفی خودکار

```
کرون (هر ۵ دقیقه)
  └─ محصولات با published_at > watermark  (ترتیب صعودی)
       ├─ در کانال پست می‌شود
       ├─ در جدول announcements ثبت می‌شود (جلوگیری از تکرار)
       └─ به مشترکان اعلان در چت خصوصی می‌رود
```

اجرای **اول** فقط نقطه‌ی شروع را ثبت می‌کند و هیچ‌چیز پست نمی‌کند؛ پس با
روشن‌شدن ربات، ۴۰ محصول قدیمی یک‌جا در کانال نمی‌ریزند. برای معرفی قدیمی‌ها
از پنل ادمین «📦 معرفی محصولات قبلی» استفاده کن.

## 🔐 جریان ورود با تلگرام

```
ربات: «🔐 ورود به سایت با تلگرام»
  └─ Worker حساب Supabase را می‌سازد (ایمیل tg<id>@telegram.shekargah.ir)
     └─ کد یک‌بارمصرف ۱۰ دقیقه‌ای → لینک /login/telegram?code=…
          └─ سایت کد را به POST /auth/exchange می‌دهد
             └─ worker با service_role نشست می‌سازد و توکن برمی‌گرداند
                └─ سایت supabase.auth.setSession(...)
```

- رمز حساب تلگرامی از `HMAC(AUTH_SECRET, telegram:ID)` مشتق می‌شود و **ذخیره نمی‌شود**.
- کد ورود فقط به‌صورت SHA-256 در D1 ذخیره می‌شود و یک‌بارمصرف است.
- `service_role` فقط داخل ورکر است؛ هرگز به مرورگر نمی‌رود.

## ⚙️ متغیرها

**غیرمحرمانه** (`wrangler.toml`):

| نام | نمونه | توضیح |
|---|---|---|
| `BOT_USERNAME` | `shekargaah_bot` | نام کاربری ربات بدون @ |
| `CHANNEL_ID` | `@shekargaah_ir` | کانال مقصد پست‌ها |
| `CHANNEL_URL` | `https://t.me/shekargaah_ir` | لینک کانال |
| `SITE_URL` | `https://shekargaah.ir` | آدرس سایت |
| `ALLOWED_ORIGINS` | خالی | دامنه‌های اضافی CORS (با کاما) |
| `ADMIN_IDS` | `1265415697,7102386004` | آیدی عددی ادمین‌ها |
| `SUPABASE_URL` | `https://xxx.supabase.co` | پروژه‌ی سایت |
| `SUPABASE_ANON_KEY` | `sb_publishable_…` | کلید عمومی (خواندن محصولات) |
| `REQUIRE_JOIN` | `1` | اجبار عضویت کانال |
| `ANNOUNCE_INTERVAL_MINUTES` | `5` | فاصله‌ی بررسی محصول تازه (اطلاعاتی) |

**محرمانه** (`wrangler secret put`):

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن @BotFather |
| `WEBHOOK_SECRET` | رشته‌ی تصادفی برای اعتبارسنجی webhook |
| `SUPABASE_SERVICE_KEY` | ساخت/ورود حساب تلگرامی |
| `AUTH_SECRET` | راز مشتق‌کردن رمز حساب‌ها |

## 🚀 راه‌اندازی

```bash
npm install
npx wrangler d1 create shekargah-bot-db     # database_id را در wrangler.toml بگذار
npm run db:init:remote
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WEBHOOK_SECRET
npx wrangler secret put SUPABASE_SERVICE_KEY
npx wrangler secret put AUTH_SECRET
npm run deploy
node scripts/set-webhook.mjs https://shekargah-bot.<subdomain>.workers.dev
node scripts/check-bot.mjs https://shekargah-bot.<subdomain>.workers.dev
```

### ⚠️ دو قدم حیاتی

1. ربات باید **ادمین کانال** باشد (چک عضویت و پست):
   `کانال → Administrators → Add Admin → ربات`
2. آیدی عددی خودت را در `ADMIN_IDS` بگذار تا `/admin` کار کند (با `@userinfobot`).

| دکمه | کار |

| 📣 محصولات اخیر | لیست محصولات سایت → ارسال فوری یا زمان‌بندی |

## 🔌 API ورکر

| مسیر | کار |
|---|---|
| `GET /health` | سلامت سرویس |
| `POST /` | webhook تلگرام (هدر `X-Telegram-Bot-Api-Secret-Token`) |
| `POST /auth/exchange` | `{code}` → `{access_token, refresh_token, user_id}` |
| `POST /auth/miniapp` | `{initData}` → توکن‌های نشست (پایه‌ی مینی‌اپ) |

CORS فقط برای `shekargaah.ir`، `shekargah.pages.dev` و `localhost` باز است.
